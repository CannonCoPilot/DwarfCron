# DFHack tools, batch 2: single most useful fact (DF 53.16, DFHack 53.16-r2)

- [flows](flows.md): It never reads DF flows (`flow_info`, OceanWave/SeaFoam/Mist). It counts blocks with the `update_liquid`/`update_liquid_twice` flags and water/magma tiles with `flow_size>0`, so a wave/mist census needs our own walk of `block.flows`/`df.global.flows`.
- [force](force.md): `force Wildlife` spawns nothing. It clears `roaming_wilderness_population_source` on visible wild units and refunds +1 to each unit's population, which lifts our quantity-0 holds to 1. It also accepts every `timed_event_type` (`WildlifeCurious`/`Mischievous`/`Flier`, `NightCreature`...) except `FeatureAttack`, and our E22 measured Migrants and Megabeast as accepted but arriving nowhere.
- [gui/biomes](gui-biomes.md): It maps each tile through its own `designation.biome` → `region_offset` → `getBiomeRgnPos` (the same decode as ours). It therefore shows tile biomes but under-reports wildlife draw sources, which are all nine `region_offset` entries per block. Its first view of each z-level costs one Lua call per tile.
- [gui/reveal](gui-reveal.md): reveal only clears `designation.hidden`. The restore snapshot lives in memory and is lost on save or unload, caverns are not marked `Discovered`, `reveal hell` force-pauses every frame, `reveal demon` is disabled in r2, and a revealed map makes plain `force Wildlife` free cavern units too.
- [markdown](markdown.md): It is the only 53.16 route to DF's creature description text. It clicks the unit sheet's tabs at hard-coded mouse coordinates and reads `main_interface.view_sheets.*_raw_str`, which is fragile UI automation and must not run on the user's game.
- [migrants-now](migrants-now.md): It is one `timed_events` insert (Migrants, player civ, `cur_season_tick+1`), almost identical to `force Migrants`. Both return success, but none of four trials in E22 brought a migrant in 36,000 ticks, so use create+makeown for citizens.
